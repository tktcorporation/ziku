`ziku push` の PR タイトルと本文を、実際に送る集合から組み立てる。

PR 本文のファイル一覧が端末のサマリーと一致するようになった。自動更新されたテンプレートの `README.md` は `Auto-updated` として本文に並び、送る内容がテンプレートと同一になって送信対象から落ちたファイルは本文にも出ない。タイトルと本文を組み立てる関数は送信対象（`PushSend`）しか受け取らないので、選択そのものから文面を作る経路は無い。

PR 本文の書式が実行経路によらず 1 つになった。`push --edit` で本文を空のまま確定した場合も、送る集合から導いた提案値を使う。PR 作成 API は本文を必須で受け取り、自前では組み立てない。

`ziku.jsonc` の自動同梱を伝えるメッセージから、利用者には意味を持たない内部参照を落とした。
