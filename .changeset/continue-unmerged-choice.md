`pull --continue` は、自動マージを試みなかったファイル（共通祖先を取得できなかった / バイナリ）について、ローカルの内容を残すかテンプレートの内容を取るかをファイルごとに選ばせてから同期ベースを確定する。ziku がそれらのファイルへ何も書いていない以上、コンフリクトマーカーが無いことは解決の証拠にならないため。`--yes` / `--force` を付けた実行では選択を代行せず、対話でのやり直しを案内して中断する。

`lock.json` の `merge.conflicts` は、パスに加えて未解決になった経路（マーカーを書き出した / 共通祖先が無い / バイナリ）を持つ。

対話実行の `push` は、テンプレート側の削除を取り消すファイルを既定で選択しない。一覧の行には削除の取り消しであることを表示する。

ref を持たないテンプレートへの PR は、リポジトリの既定ブランチへ向ける。既定ブランチが `master` などのテンプレートでも PR を作成できる。既定ブランチを取得できなかった場合は、宛先の決め方を案内して中断する。
