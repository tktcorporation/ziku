ファイル差分（`FileDiff`）を種別ごとの判別 union で表現し、種別に対応する内容が必ず存在するようにする。`added` はローカル側、`deleted` はテンプレート側、`modified` / `unchanged` は両側の内容を持つ。内容の欠損を空文字列で埋めるフォールバックが不要になり、次の誤表示が起きなくなる。

- テンプレート側の内容を空とみなした patch が生成される
- 削除・追加されたファイルの変更行数が 0 行として表示される

差分結果（`DiffResult`）から集計フィールドを外し、ファイル一覧から数える導出関数にする。`ziku diff` / `ziku push` が表示する種別ごとの件数は、常に表示中のファイル一覧と一致する。
