テンプレートが削除した `.ziku/ziku.jsonc` を、push の自動同梱が復活させないようにする。

テンプレートが `ziku.jsonc` を削除しローカルにその編集が残っている状態では、設定ファイルは既定の送信対象から外れる（テンプレート側の削除を無確認で取り消さないため）。この状態で `ziku push --yes` を実行すると、選択とは別に動く `ziku.jsonc` の自動同梱が、今回の push に関係するパターンだけを持つ縮小版の設定ファイルを作って PR に載せていた。自動同梱も既定選択が外したファイルには手を出さない。

スコープ限定の `ziku.jsonc` を組み立てる計算は、テンプレートに元の文書があるときだけ内容を返す。文書が無ければ作れるのは「テンプレートの内容 + 追加分」ではなく「追加分だけの新しい文書」なので、呼び出し側が両方のケースを扱う。
