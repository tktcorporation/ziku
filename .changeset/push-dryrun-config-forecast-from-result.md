`ziku push --dry-run` の `.ziku/ziku.jsonc` 同梱予告を、実 push と同じ判断から出すようにする。

同梱するかは 2 段で決まる。送信対象に必要なパターンがあるかという純粋な判断と、テンプレートに足す先の `ziku.jsonc` があるかという I/O を伴う判断で、後段は伝播そのものを実行しないと結論が出ない。予告は前段の条件を書き写していたため、テンプレートに `ziku.jsonc` が無いプロジェクトで「`.ziku/ziku.jsonc` も push される」と出しながら、実 push は送らなかった。

伝播の関数が同梱の決着を判別可能 union で返し、実 push の案内も dry-run の予告もその値から作る。
