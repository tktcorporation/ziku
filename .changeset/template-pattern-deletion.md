テンプレートが `ziku.jsonc` から include / exclude パターンを外したとき、その削除を利用リポジトリへ伝播させる。

`lock.json` の `base.patterns` に「前回の同期時点でテンプレートが宣言していたパターン」を記録し、テンプレートの現在の宣言・ローカルの宣言と 3 者で突き合わせる。これにより「テンプレートが外した」と「ローカルが独自に足した」を区別できるようになり、前者だけがローカルの宣言から落ちる。ローカルが外したパターンはテンプレートへ送り返さないので、1 つのプロジェクトの opt-out が全下流へ波及することはない。

記録を持たない既存の `lock.json` では判断材料が無いため、これまでどおり加法 union で動く（何も消さない）。記録は次回の `pull` / `push` / `init` で入る。

パターンを外すこととファイルを消すことは別に扱う。外れたパターンに一致するファイルは、その回の分類には載るので、テンプレートが同じ変更で削除していれば削除候補として提示される。ローカルの編集を理由に残したファイルは同期ベースから外れ、以降は未追跡として扱われる。
