GitHub へ一時的に問い合わせられないときでも `ziku push` が PR を作れるようにする。

`source.ref` を持たないテンプレートへの PR は、リポジトリの既定ブランチへ向ける。既定ブランチを引けなかったときの扱いは、テンプレートの取得先を決めるときと同じ規則に従う。

- トークンを拒否された（401）: PR を作らず、トークンの直し方を案内して中断する。控えた既定ブランチがあっても宛先にしない。
- レート制限・5xx・ネットワーク断: `.ziku/lock.json` に控えた既定ブランチを宛先にして PR を作る。テンプレートの取得が控えへ倒れて成立する実行では、PR の作成も成立する。控えが無いときだけ、宛先の決め方を案内して中断する。

`source.ref` にブランチが指定されていればそれが宛先になり、既定ブランチは問い合わせない。タグ・コミットへ固定されたテンプレートへは PR を作れないので、`lock.json` の直し方を案内して中断する。
