`ziku push` が、ユーザー側の状況で起きた失敗を ziku の不具合として報告しないようにする。

次の失敗は、原因とスタックトレースの代わりに、取るべき行動を示すメッセージで報告する。

- トークンの失効 (401) — `gh auth login` での再ログインか、環境変数の更新を促す
- レート制限 (429 / 403 + rate limit ヘッダ) — 待つか認証するかを、リセットまでの残り時間付きで案内する。連投を弾く secondary rate limit も同じ扱いにする
- 権限不足の 403 — トークンの書き込み権限と、リポジトリが fork を許可しているかの確認を促す
- GitHub への接続断・名前解決失敗・タイムアウト — 接続とプロキシ設定を確かめて実行し直すよう案内する
- ローカルテンプレートへの書き込みが権限・空き容量で失敗 — 書き込み先のパスを示す

これらに当てはまらない失敗は、引き続き原因とスタックトレースをそのまま表示する。
