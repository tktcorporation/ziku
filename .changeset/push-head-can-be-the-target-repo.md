テンプレートリポジトリの所有者が自分自身のとき、`ziku push` / `ziku setup --remote` が PR を作れるようにする。

PR の head は base と共通の履歴を持つ場所であればよく、それを満たす形は「対象リポジトリの fork」と「対象リポジトリ本体」の 2 つある。head の置き場所を fork に限っていたため、認証ユーザーが対象リポジトリの所有者である構成では、対象リポジトリ自身が「同名だが fork ではないリポジトリ」と判定され、そのリポジトリの改名か削除を促して必ず失敗していた。案内に従うと、そのテンプレートを使う全プロジェクトの同期元が消える。

所有者が一致する場合は fork を挟まず、対象リポジトリ本体に同期ブランチを作って PR を出す。所有者の比較は大文字小文字を区別しない（GitHub のログイン名の規則に合わせる）。
