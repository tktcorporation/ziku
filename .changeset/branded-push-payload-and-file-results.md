テンプレートへ送る内容と、ファイル操作結果のパスを型で絞る。

PR に載せる内容は `PushContent`（コンフリクトマーカー非混入が検証済み）、削除するパスは `DeletablePath`（ziku 自身の設定ファイルを作れない）でしか渡せなくなった。どちらの brand も送信ペイロードを組み立てる層に閉じていたため、PR 作成 API を直接呼ぶ経路は検証を通さずにマーカー入りの内容や設定ファイルの削除を送れた。

ファイル操作結果のパスと、ファイルの書き込み・コピーを行うヘルパーの引数も brand 付きにした。結果のパスは init が同期ベースを記録するときにテンプレートの走査結果と突き合わせる鍵で、表現のずれた 1 件は「init が書いたのにベースに載らない」形で次の pull をコンフリクトにする。
