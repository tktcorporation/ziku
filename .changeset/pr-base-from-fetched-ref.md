PR の宛先ブランチを、テンプレートの取得に使った参照から導く。

`ref` を持たない GitHub ソースへの `ziku push` は、1 回の実行で既定ブランチを 2 回問い合わせていた（テンプレートの取得先を決めるときと、PR の宛先を決めるとき）。問い合わせはテンプレートの取得先を決める 1 箇所に閉じ、コマンドのコンテキストが確定した取得先を後段へ渡す。未認証で 60 req/h しかない予算の消費が半分になる。

宛先を決める関数は、問い合わせ結果ではなく確定した取得先だけを受け取る。宛先が取得先と別のブランチになる組み合わせを、型として作れない。
