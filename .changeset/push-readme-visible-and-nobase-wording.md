テンプレートの README に `<!-- FEATURES:START -->` / `<!-- FILES:START -->` マーカーがあるとき、`ziku push` は同期対象一覧を反映した README をテンプレートへ送る。

送るファイルはユーザーが選んだものだけ、という原則の例外になるので、送信前に理由を伝える。README のマーカー間は `.ziku/ziku.jsonc` の include から導出される派生物で、追跡ファイルと同じ選択単位にすると設定と食い違った README を選べてしまう。そのため選択の対象にはせず、サマリに `(auto-updated)` の行として並べ、`Also pushing README.md — ...` で導出元を名指ししてから確認プロンプトを出す。`--dryRun` のプレビューでも同じ内容を予告する（プレビューは README へ書き込まない）。

共通祖先を取得できずに自動マージを諦めたときの案内を、実際に起きることへ合わせる。ziku はマージを試みず、ローカルのファイルにも一切書き込まない。コンフリクトマーカーが入ったと読める文言をやめ、対象ファイルに触れないまま未解決として扱うことを伝える。
