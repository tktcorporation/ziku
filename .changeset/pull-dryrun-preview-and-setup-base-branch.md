`pull --continue --dryRun` は、自動マージできなかったファイルが残っていてもプレビューを表示して正常終了する。`--yes` / `--force` を付けた実行では、そのまま実行するとファイルごとの選択を求められて中断することを併せて表示する。

`pull` は、テンプレートからもワークツリーからも既に消えているファイルを削除候補として提示せず、削除したというログも出さない。同期ベースからはエントリを落とすため、繰り返し実行しても状態は収束する。

`setup --remote` が作る PR は、テンプレートリポジトリの既定ブランチへ向ける。既定ブランチが `master` などのリポジトリでも PR を作成できる。既定ブランチを取得できなかった場合は `main` を仮定せず、宛先の決め方を案内して中断する。
