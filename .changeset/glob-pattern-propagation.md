glob で追跡したパターンを push でテンプレートへ伝播させる。

`ziku track '.claude/rules/*.md'` のように glob を追跡したプロジェクトで `ziku push --files .claude/rules/a.md` を実行すると、ファイル本体だけがテンプレートへ届き、`ziku.jsonc` の include パターンが届かなかった。パターンとファイルパスを同じ文字列として突き合わせていたため、glob はどのパスとも一致せず「このファイルに関係するパターンは無い」と判定されていた。パターンを追跡していない他のプロジェクトは `init` / `pull` でそのファイルを拾えず、2 回目の push まで配られなかった。

パターンとパスの照合を glob の解決に置き換える。個別ファイルのパスを include に書く運用（`ziku push` の未追跡ファイル追記など）はこれまでどおり文字列の一致で判定するので、ディスク上に無いファイル（削除して push するもの）のパターンも取りこぼさない。

あわせて、パス（絶対パス / 同期の基点からの相対パス / glob パターン）とハッシュ（内容ハッシュ / コミット SHA / GitHub の blob SHA）をそれぞれ別の型として区別し、取り違えをコンパイルエラーにした。
