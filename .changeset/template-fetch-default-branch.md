テンプレートをリポジトリの既定ブランチから取得する。`.ziku/lock.json` の `source.ref` が指定されていればその ref から、無ければ GitHub API で解決した既定ブランチから取り寄せる。既定ブランチが `master` などのリポジトリでも、差分比較に使うツリー・`lock.base.ref` に記録するコミット SHA・push が PR を向ける宛先ブランチが同じブランチを指す。

既定ブランチを解決できないときは取得を中断し、GitHub への到達性（ネットワーク・トークン）を確かめるか `source.ref` で取得先を明示するよう案内する。どのブランチを取ればよいか決まらないまま既定の `main` へ倒すと、記録済みのベースと関係のないツリーを共通祖先として 3-way マージが進み、その食い違いは差分にもマージ結果にも現れないため。
