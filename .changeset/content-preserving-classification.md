同期するファイルの内容を、種別の判定とマージの形の復元で壊さないようにする。

テキストかバイナリかは、内容全体に NUL があるかで判定する。バイト列で読むときも、差分・push が内容を運ぶ string チャネル上で見るときも同じ結果になり、テキストとして読んだ内容がバイナリとして符号化されて U+00FF を超える文字が潰れることがなくなる。バイナリは種別を示す目印を付けて運ぶので、内容だけからの推測で符号化を誤ることもない。

utf-8 としてデコードと再エンコードを往復できない内容（Shift_JIS / EUC-JP / latin1 など、NUL を持たない非 utf-8 のテキスト）はバイナリとして扱う。行単位のマージ対象から外れ、テンプレートへは元のバイト列のまま送られる。ローカルとテンプレートのハッシュが一致するようになるので、そのファイルが毎回 push 候補に出続けることもなくなる。

ローカルで削除されたファイルをテンプレート側の変更とマージするとき、改行コードと BOM はテンプレート側の形を採る。CRLF や BOM を持つテンプレートファイルがマージ結果で LF・BOM 無しに変わり、その形が次の push でテンプレートへ送られることがなくなる。ローカルとテンプレートの両方が空なら結果も空になる。
